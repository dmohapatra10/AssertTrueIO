How This Differs From Chapter 14

Chapter 14 assembled one agent's internal architecture — Planner, Browser Tools, Observation, Evaluator, Recovery, all inside a single process. This chapter operates one level up: multiple agents, an MCP server serving several teams, CI/CD pipelines, evidence storage, and audit logs, all as one real, deployed system a whole organization depends on.

Common Mistakes

  • Expecting new testing techniques in this chapter. Like Chapter 14, this chapter's real work is architecture and assembly — every component traces to something this track already built and explained.
  • Treating system-level concerns as a bigger version of single-agent concerns. Multiple agents sharing infrastructure introduce genuinely new questions — shared cost, shared security boundaries, shared observability — that a single agent never faced.
