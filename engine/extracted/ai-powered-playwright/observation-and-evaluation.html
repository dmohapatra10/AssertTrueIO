Step-by-Step Implementation — Observation, Feeding Back Into the Conversation

// src/agent-observe.ts
import Anthropic from '@anthropic-ai/sdk';
import { AgentState } from './agent-state';

export function recordObservation(
  state: AgentState, toolUseId: string, resultText: string
): void {
  state.conversationHistory.push({
    role: 'assistant',
    content: [{ type: 'tool_use', id: toolUseId, name: '', input: {} }],
  });
  state.conversationHistory.push({
    role: 'user',
    content: [{ type: 'tool_result', tool_use_id: toolUseId, content: resultText }],
  });
}

Code Explanation

This is Anthropic's real, required format for a tool result — the model needs to see its own tool call acknowledged, followed by the actual result, before it can reason about what to do next. This is genuinely different from Chapter 5's observation, which just returned a plain object; here, the observation has to be threaded back into the conversation in the specific shape the tool-calling protocol requires.

Step-by-Step Implementation — The Evaluator, Built From Scratch

// src/agent-evaluator.ts
import { anthropic } from './ai-client';
import { AgentState } from './agent-state';

export interface EvaluationResult {
  objectiveLikelyMet: boolean;
  reasoning: string;
  confidence: 'high' | 'medium' | 'low';
}

export async function evaluateProgress(
  state: AgentState
): Promise<EvaluationResult> {
  const response = await anthropic.messages.create({
    model: 'claude-sonnet-4-6',
    max_tokens: 500,
    system: `Evaluate whether this testing objective has
genuinely been achieved, based on the FULL conversation so
far. Be honest — do NOT report success unless the evidence
genuinely supports it.`,
    messages: [
      ...state.conversationHistory,
      { role: 'user', content: `Objective: "${state.objective}"
Has this been genuinely achieved? Respond with ONLY valid JSON:
{"objectiveLikelyMet": boolean, "reasoning": string,
"confidence": "high" | "medium" | "low"}` },
    ],
  });

  const textBlock = response.content.find((b) => b.type === 'text');
  return JSON.parse((textBlock as any).text);
}

Why It Matters — This Is a Genuinely New Judgment Call

Notice the system prompt explicitly warns against overstating success — this connects directly to Chapter 9's honest-confidence discipline, now applied to the agent's own self-assessment. An agent that's overly eager to declare objectiveLikelyMet: true would terminate prematurely, missing real problems; one that's never confident would loop indefinitely, hitting Chapter 13's limits without ever recognizing genuine success. Getting this evaluation honest is what makes autonomous termination trustworthy at all.

Common Mistakes

  • Letting the model that just took an action also evaluate whether the objective is met, in the same reasoning step. This risks the same overconfidence problem Chapter 9's own confidence-assessment page addressed — evaluation deserves its own, separate, honest pass.
  • Skipping the required tool-result format when recording an observation. Anthropic's API expects this specific structure — omitting it breaks the conversation's ability to continue coherently.

Best Practices

  • Keep evaluation as a genuinely separate, explicit step from planning and execution — never assume success without asking the question directly.
  • Instruct the evaluator explicitly toward honesty over optimism, the same discipline Chapter 9 established for failure-analysis confidence.

Hands-On Exercise

Run evaluateProgress against a deliberately incomplete conversation history — one where only a navigation action has happened, nothing else. Confirm the evaluator correctly reports objectiveLikelyMet: false with honest, low confidence, rather than prematurely declaring success.
