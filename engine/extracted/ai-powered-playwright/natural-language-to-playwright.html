An Honest Note on Scope

This chapter builds a real, working version of this loop — deliberately simpler than Chapter 14's full autonomous agent, which adds memory across many steps, recovery from real failures, and formal termination guardrails. Treat this chapter as the genuine, working foundation Chapter 14 extends, not a competing approach.

Common Mistakes

  • Planning every action up front and executing blindly. This chapter's whole architecture depends on observing the real page after each action — a plan made before anything runs can't account for what the browser actually shows.
  • Skipping validation because "it's just a click." Chapter 5's own validation page is explicit that every action, however small, gets checked before touching a real browser.

Best Practices

  • Build this chapter's eight pages in order — each one is a genuine, working piece of the same instruction, not a standalone example.
  • Keep the Observation → Next Action loop in mind throughout — it's what separates this chapter from Chapters 3 and 4's one-shot generation.
