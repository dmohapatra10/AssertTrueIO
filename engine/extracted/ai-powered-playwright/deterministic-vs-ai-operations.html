Introduction — The Rule, Seventeen Chapters Later

Chapter 2 stated it once: if a decision has one correct answer given known inputs, write deterministic code; reach for AI specifically where genuine judgment is required. Every chapter since has applied this rule somewhere. This page is the complete, honest accounting — reviewing this entire track through that one lens.

Why It Matters — Seeing the Whole Pattern at Once

Laid out together, a real pattern emerges: AI earned its place specifically at moments of genuine ambiguity or creativity — generating something new, judging quality, reasoning about why something happened, deciding whether a goal is met. Everything else — counting, searching a known list, matching against a fixed set of categories, mapping one known thing to another — stayed deterministic code, every single time, across this entire track.

Why It Matters — A Real Test for Anything New

Before adding an AI call to your own project, this track's real, working test is: does this decision have one correct answer, given known inputs? If yes, write the deterministic version — every single example on this page's "deterministic" list would have been a genuine, real waste of cost and latency if AI had been used instead. If no — if the task genuinely requires judgment, creativity, or reasoning through ambiguity — AI is earning its real place, the same way it did throughout this track's "genuine AI judgment" list.

Common Mistakes

  • Reading this audit once and assuming the lesson is "use less AI." The real lesson is matching the tool to the actual question — this track's AI judgment list is just as long and just as real as its deterministic list.
  • Treating a borderline case, like classifyFailure, as obviously one or the other without genuine thought. This page's side-by-side example shows real judgment calls exist about where exactly the line falls — the test is the question to ask, not a mechanical rule to apply thoughtlessly.

Best Practices

  • Revisit this audit periodically as your own project grows — a function that started as genuine AI judgment might, over time, reveal a pattern deterministic code could handle just as well.
