Introduction

Every later chapter's code assumes this project structure exists. Getting it right once here means every later "add this file" instruction just works, without revisiting setup.

Step-by-Step Implementation

# Create and enter the project directory
mkdir shopsmart-ai-testing
cd shopsmart-ai-testing

# Initialize a Node.js project
npm init -y

# Install Playwright and its test runner
npm install -D @playwright/test

# Install the Anthropic SDK — this chapter's concrete AI
# provider example, per this chapter's own vendor-neutral note
npm install @anthropic-ai/sdk

# Install TypeScript tooling and environment variable support
npm install -D typescript ts-node @types/node dotenv

# Download the actual browser binaries Playwright needs
npx playwright install

# Initialize TypeScript configuration
npx tsc --init

Code Explanation

Two dependencies matter most here. @playwright/test is Playwright's own test runner — the same tool the rest of the existing Playwright tutorial uses. @anthropic-ai/sdk is this chapter's chosen AI client library — the thing that actually sends requests to the model and gets responses back, covered in depth two pages from now.

The Folder Structure This Tutorial Assumes

shopsmart-ai-testing/
├── src/
│   ├── ai-client.ts        # this chapter's Creating the AI
│   │                         Client page
│   ├── generate-scenarios.ts  # From Prompt to Structured
│   │                             Test Scenarios
│   └── generate-tests.ts        # Generating Playwright Code
│                                   from Scenarios
├── tests/
│   └── generated/                # AI-generated test files
│                                    land here
├── .env                             # real credentials, never
│                                       committed
├── .gitignore
├── package.json
└── tsconfig.json

Expected Result

Running npx playwright test --list should complete without error, even with zero tests written yet — this confirms Playwright's own test runner is correctly installed and configured before any AI code enters the picture.

Common Mistakes

  • Skipping npx playwright install. Without it, Playwright's package is installed but the actual browser binaries aren't — tests will fail with a confusing "browser not found" error that has nothing to do with AI at all.
  • Installing the AI SDK as a dev dependency when it's needed at runtime. Unlike TypeScript tooling, @anthropic-ai/sdk is a real runtime dependency — installed without -D, deliberately, above.

Best Practices

  • Confirm Playwright's own test runner works in isolation (an empty tests/ folder is fine) before adding any AI-generated code on top of it.
  • Keep AI-related source code in its own src/ folder, separate from the tests/ folder Playwright's runner actually executes — this chapter's structure keeps generation and execution cleanly separated.

Hands-On Exercise

Run through this page's setup commands yourself, then run npx playwright test --list to confirm it completes cleanly. If it doesn't, resolve that before continuing — every later page in this chapter builds directly on this working foundation.

Key Takeaways

  • This project's structure deliberately separates AI-related source code from the tests folder Playwright's runner executes.
  • @anthropic-ai/sdk is a real runtime dependency, not a dev-only tool, since it's used when generating scenarios and code, not just during development.
  • Confirming Playwright's test runner works before adding AI code isolates any later problems to the AI layer specifically, not the foundation underneath it.
