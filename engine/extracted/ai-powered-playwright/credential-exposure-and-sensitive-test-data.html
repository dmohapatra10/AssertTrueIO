Step-by-Step Implementation — Scanning Evidence Before It Reaches a Prompt

// src/scan-evidence-for-secrets.ts
import { EvidenceBundle } from './capture-evidence';

const SECRET_PATTERNS = [
  /[a-zA-Z0-9_-]{20,}\.[a-zA-Z0-9_-]{20,}\.[a-zA-Z0-9_-]{20,}/, // JWT-shaped
  /sk-[a-zA-Z0-9]{20,}/, // common API key prefix pattern
  /Bearer\s+[a-zA-Z0-9_-]{20,}/i,
];

export function scanEvidenceForSecrets(bundle: EvidenceBundle): string[] {
  const findings: string[] = [];
  const textFields = [
    bundle.errorMessage, bundle.stackTrace,
    ...bundle.consoleLogs, ...bundle.networkFailures,
  ];

  for (const field of textFields) {
    for (const pattern of SECRET_PATTERNS) {
      if (pattern.test(field)) {
        findings.push(`Possible secret matching pattern in: "${field.slice(0, 40)}..."`);
      }
    }
  }
  return findings;
}

Code Explanation

This is a real, if imperfect, pattern-based scan — the same honest framing Chapter 15's own guard function used. It catches common, recognizable secret shapes (JWTs, typical API key prefixes, bearer tokens), not every conceivable credential format. Its job is flagging evidence for review before it reaches an AI prompt, not guaranteeing perfect detection.

Why It Matters — This Closes a Real Gap Between Two Earlier Chapters

Chapter 8 protected generated data at its source; Chapter 16 protected secrets at the CI level. Neither one sits between real, captured runtime evidence and the AI prompt that consumes it — exactly the gap this page's scan closes, extending this track's existing privacy discipline to a case those earlier pages didn't anticipate.

Common Mistakes

  • Assuming Chapter 8's synthetic-data discipline alone covers this risk. Chapter 8 addressed data this track's own code generates — this page addresses real, unexpected values that leak into evidence from the application under test itself.
  • Treating a clean scan result as a guarantee of no secrets present. Like Chapter 15's own guard, this is pattern-based and genuinely imperfect — a real credential in an unrecognized format could still slip through.

Best Practices

  • Scan captured evidence for secret patterns before it ever reaches an AI prompt, as a standard step in Chapter 9's own pipeline.
  • Treat a positive scan result as a reason to halt and investigate, never something to route around to keep a pipeline moving.
