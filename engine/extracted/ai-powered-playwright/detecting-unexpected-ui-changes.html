Introduction

The previous page checked one screenshot against a stated requirement. This page checks two screenshots against each other — a genuinely different, comparative question this track hasn't asked visually until now.

Step-by-Step Implementation

// src/detect-ui-changes.ts
import { anthropic } from './ai-client';

export interface ChangeAssessment {
  changeDetected: boolean;
  looksIntentional: boolean;
  description: string;
}

export async function assessVisualChange(
  beforeBase64: string, afterBase64: string
): Promise<ChangeAssessment> {
  const response = await anthropic.messages.create({
    model: 'claude-sonnet-4-6',
    max_tokens: 500,
    messages: [{
      role: 'user',
      content: [
        { type: 'text', text: 'BEFORE:' },
        { type: 'image', source: { type: 'base64', media_type: 'image/png', data: beforeBase64 } },
        { type: 'text', text: 'AFTER:' },
        { type: 'image', source: { type: 'base64', media_type: 'image/png', data: afterBase64 } },
        { type: 'text', text: `Compare these two screenshots of
the same page. Describe any real difference. Judge whether it
looks like an intentional design change or something genuinely
broken (misalignment, missing content, overlapping elements).

Respond with ONLY valid JSON:
{"changeDetected": boolean, "looksIntentional": boolean,
"description": string}` },
      ],
    }],
  });

  const textBlock = response.content.find((b) => b.type === 'text');
  return JSON.parse((textBlock as any).text);
}

Code Explanation

Notice the content array now carries two labeled images, not one — the explicit "BEFORE:" and "AFTER:" text blocks matter genuinely here, giving the model clear reference points for which image is which before it reasons about what changed between them.

Why It Matters

This is the genuine answer to Chapter 17's opening page's core gap — a pixel diff would flag both examples above identically, as "different," with no way to distinguish them. This comparative check gives a real, if imperfect, first-pass judgment before a human needs to look at either pair themselves.

Common Mistakes

  • Sending unlabeled images in the content array. Without the explicit "BEFORE:" and "AFTER:" text blocks, the model has to guess which image is which — labeling removes that ambiguity entirely.
  • Treating looksIntentional: true as a final, unreviewed verdict. This is a genuine first-pass judgment, not a replacement for human sign-off on an actual design change — Chapter 17's closing page addresses this limitation directly.

Best Practices

  • Always label multiple images explicitly in the content array — never rely on the model inferring order or identity from position alone.
  • Treat this check's output as a genuine, useful first pass — routing "looks broken" results for immediate human review, and "looks intentional" results for lighter-weight confirmation.
