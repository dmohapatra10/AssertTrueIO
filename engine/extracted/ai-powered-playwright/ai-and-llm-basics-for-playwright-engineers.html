Why This Chapter Stays Short

You don't need a machine learning background to use AI well in testing — you need a working, practical understanding of a handful of concepts, each of which this chapter ties directly to something you already know from Playwright. No generic AI examples here; every concept gets a ShopSmart-specific one instead.

Common Mistakes

  • Skipping this chapter because "AI is just a chatbot." Structured responses and tool calling specifically — covered here — are what make the rest of this tutorial's automation genuinely reliable, not just conversational.
  • Over-investing in deep LLM theory before writing any code. This chapter deliberately stays practical; Chapter 3 gets you to working code immediately after.

Best Practices

  • Read this chapter's six pages in order — each one builds a term the next one uses without re-explaining it.
  • Keep translating each new concept back to a Playwright equivalent as you read — that's exactly how this chapter is written.

Key Takeaways

  • This chapter is deliberately short and practical — enough working knowledge to build the rest of this tutorial confidently, not a full AI course.
  • Every concept is anchored to a concrete Playwright or ShopSmart example, not a generic AI illustration.
  • By the end, you'll have the vocabulary Chapter 3's working code depends on.
