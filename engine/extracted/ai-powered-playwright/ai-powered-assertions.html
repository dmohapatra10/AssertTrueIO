The Example This Chapter Keeps Returning To

await expect(page.getByRole('heading', {
  name: 'Order Confirmed'
})).toBeVisible();

There's exactly one correct answer here — the heading either says "Order Confirmed" and is visible, or it doesn't. AI adds nothing to this check except cost, latency, and a small, genuine risk of getting it wrong. Chapter 2's own core rule already answers this — this chapter is about applying that rule specifically, carefully, to assertions.

Two Genuinely Different Roles, Never Conflated

ROLE 1 — AI WRITES the assertion CODE for you
  Still fully DETERMINISTIC once written — AI just helped
  produce toBeVisible(), toHaveText(), toHaveURL() calls

ROLE 2 — AI JUDGES content with NO single correct string
  "Does this error message genuinely make sense to a real
  user?" — a GENUINE judgment call, no exact match possible

This chapter keeps these two roles carefully separate throughout — conflating them is exactly how a team ends up either avoiding AI everywhere, or using it everywhere it doesn't belong.

Common Mistakes

  • Assuming "AI-powered assertions" means every check now involves a judgment call. Most of this chapter's own examples are about AI helping write ordinary, deterministic assertions — not replacing them with something fuzzier.
  • Using AI judgment for a check that has one clear, known correct value. This chapter's closing page is explicit, using the exact example above, about why that's a genuine mistake.

Best Practices

  • Before writing any assertion, ask which of this chapter's two roles actually applies — that answer shapes everything else.
  • Default to deterministic assertions; require a genuine reason, covered on this chapter's fifth page, before reaching for AI judgment.

Key Takeaways

  • AI can help write deterministic assertions without changing what makes them deterministic — that's Role 1, and it's the safer, more common case.
  • AI judgment belongs specifically to content with no single correct string to match — that's Role 2, genuinely narrower in scope.
  • Chapter 2's exact-versus-judgment rule is the same rule this chapter applies, now specifically to assertions.
