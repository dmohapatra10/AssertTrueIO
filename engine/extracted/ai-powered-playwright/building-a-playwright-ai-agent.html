Nothing Here Is New — Everything Gets Assembled

This is a deliberately different kind of chapter. Chapter 5 built planning and observation. Chapter 6 built locator intelligence. Chapter 9 built evidence capture. Chapter 11 built recovery. Chapter 13 built exploration strategy and safety controls. This chapter's real work is architectural: combining all of it into one real, persistent PlaywrightAgent class — and, for the first time in this track, using Anthropic's actual tool-calling API rather than the JSON-prompting pattern earlier chapters used as a simpler stepping stone.

Common Mistakes

  • Expecting genuinely new techniques in this chapter. Every real capability already exists from earlier chapters — this chapter's value is assembly and architecture, not new capability.
  • Building this agent before working through the earlier chapters it depends on. Every function this chapter's pages call was built and explained in detail somewhere earlier in this track.

Best Practices

  • Keep this chapter's architecture diagram visible while reading — each page fills in exactly one box.
  • Trace every function call in this chapter back to the earlier page that built it — the connections are deliberate and worth following.

Key Takeaways

  • This chapter assembles, rather than introduces, every real capability this track has built so far.
  • Tool calling, promised conceptually back in Chapter 2, finally gets a real, working implementation here.
  • The result is one persistent Agent class that receives a genuine objective and autonomously performs a controlled, bounded browser workflow.
