Step-by-Step Implementation

// src/capstone-pipeline.ts (stage 6)
import { generateMarkdownReport } from './generate-failure-report';
import { anthropic } from './ai-client';

export async function generateCapstoneReport(pipelineResults: {
  plan: any; execution: any; evaluation: any; rootCause: any; revalidation: any;
}) {
  // CONFIDENCE, assessed as its OWN, SEPARATE step — Chapter
  // 14'S own discipline, NOW applied to this CAPSTONE'S
  // ENTIRE run, not just one AGENT'S single objective
  const confidencePrompt = `Given this complete pipeline run:
${JSON.stringify(pipelineResults)}

Rate honest confidence (high, medium, low) that this represents
a GENUINELY resolved issue, based ONLY on what the evidence
ACTUALLY shows.`;
  const confidenceResponse = await anthropic.messages.create({
    model: 'claude-sonnet-4-6', max_tokens: 300,
    messages: [{ role: 'user', content: confidencePrompt }],
  });

  return {
    summary: 'ShopSmart checkout verification — discount code stacking bug',
    ...pipelineResults,
    confidence: confidenceResponse.content,
  };
}

Code Explanation

Confidence is assessed only after every other stage's real output already exists — the exact same discipline Chapter 14's own Evaluator applied to a single agent's objective, now applied to this capstone's entire, multi-stage run. This ordering matters for the same reason it mattered in Chapter 14: an honest assessment needs the complete picture already in front of it.

Why It Matters — This Report Is the Real Payoff of the Whole Pipeline

Every earlier stage's careful, honest work culminates here — a human reading this report gets the complete, real story: what was checked, what was found, why it happened, what was done about it, and how confident this capstone genuinely is that it's actually resolved. Common Mistakes

  • Assessing confidence before the revalidation stage completes. A confidence rating made before knowing whether the fix actually worked would be assessing the wrong, incomplete picture — this stage deliberately runs last.
  • Omitting the specific, real evidence behind each claim. A report that just says "fixed" loses exactly the traceability this capstone's earlier stages worked to establish.

Best Practices

  • Assess confidence only after every other stage's real output is complete, following Chapter 14's own established ordering.
  • Keep every claim in the final report traceable to a specific, real earlier stage — never summarize away the evidence trail.
