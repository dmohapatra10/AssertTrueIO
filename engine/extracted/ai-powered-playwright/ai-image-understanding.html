Introduction — Genuinely New Mechanics

Every prompt this track has sent so far has been text describing a situation — an error message, a page structure, a list of actions. This page sends something genuinely different: the actual pixels of a real screenshot, as an image the model can see directly.

Step-by-Step Implementation

// src/ai-image-understanding.ts
import { Page } from '@playwright/test';
import { anthropic } from './ai-client';

export async function describeScreenshot(page: Page): Promise<string> {
  const buffer = await page.screenshot();
  const base64Image = buffer.toString('base64');

  const response = await anthropic.messages.create({
    model: 'claude-sonnet-4-6',
    max_tokens: 500,
    messages: [{
      role: 'user',
      content: [
        {
          type: 'image',
          source: { type: 'base64', media_type: 'image/png', data: base64Image },
        },
        { type: 'text', text: 'Describe what this page shows, in plain language.' },
      ],
    }],
  });

  const textBlock = response.content.find((b) => b.type === 'text');
  return (textBlock as any)?.text ?? '';
}

Code Explanation

The real, genuinely new piece is the content array — instead of a single string, it's a list of blocks, one image block carrying the actual base64-encoded screenshot, and one text block carrying the instruction. This is the real shape every remaining page in this chapter builds on; nothing about it is unique to this specific example.

Why It Matters — Already Genuinely Useful, On Its Own

Even this simple description is worth something the pixel diff from the previous page never provides — actual, readable meaning. A human reviewing a failed test can read this description and immediately understand what the page showed, without opening the screenshot file themselves. This is the real foundation the rest of this chapter builds increasingly specific, structured checks on top of.

Common Mistakes

  • Sending an uncompressed, full-resolution screenshot without considering size. Image tokens genuinely cost more than text tokens — Chapter 18's later cost chapter covers this directly, but it's worth keeping in mind from this very first example.
  • Forgetting the correct media_type for the actual image format. Playwright's default screenshot format is PNG — sending JPEG-formatted bytes with a PNG media type, or vice versa, will cause the model to misread the image entirely.

Best Practices

  • Keep the content array structure — image block, then text block — as the standard pattern for every visual check this chapter builds afterward.
  • Match media_type to the actual format of the bytes you're sending, every time.
