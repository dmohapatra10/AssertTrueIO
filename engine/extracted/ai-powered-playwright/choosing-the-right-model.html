Why It Matters — The Real Difficulty Genuinely Varies

Classifying a failure into one of seven known, well-defined categories, given clear evidence, is a genuinely bounded task — the model isn't inventing anything, just matching a pattern to a known list. Generating a genuinely novel exploratory hypothesis, or reasoning through why several alternative explanations don't fit the evidence, is real, harder reasoning work. Treating both as needing identical capability wastes real money on the easier task, or under-serves the harder one.

Why It Matters — This Is a Real, Independent Cost Lever

Model selection is genuinely separate from the caching and prompt-optimization techniques this chapter's later pages cover — it's a decision made once, per call type, rather than something applied per request. Getting it right once, for each of this track's own recurring call types, compounds across every future run at that call site, for real, ongoing savings.

Common Mistakes

  • Using the most capable available model for every single call, "to be safe." This page's audit shows several of this track's own calls are genuinely bounded, pattern-matching tasks that don't need it.
  • Using a smaller model for genuinely open-ended reasoning, like exploratory hypothesis generation. This risks weaker, less useful output for exactly the kind of task where real reasoning capability matters most.
