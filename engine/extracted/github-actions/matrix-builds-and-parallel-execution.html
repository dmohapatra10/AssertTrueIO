ShopEasy's test suite takes 30 minutes to run sequentially. The team needs it down to something closer to 10, without cutting any actual tests. Before reading further: what would you try? Hold that thought — this chapter's third page answers this directly, with matrix-based parallelization as the real, practical solution.

Common Mistakes to Watch For

  • Copy-pasting a job multiple times for each version or OS combination, instead of using a matrix to express the same idea once.
  • Adding every possible combination to a matrix without considering whether they're all genuinely necessary — more combinations means more real CI time and cost.
  • Assuming matrix jobs share any state with each other — each combination genuinely gets its own separate, fresh runner.
