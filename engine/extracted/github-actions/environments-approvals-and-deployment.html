Notice the asymmetry, deliberately: deploying to Test happens automatically, right after tests pass. Deploying to Production requires an actual human to say yes, first. This chapter is about why that asymmetry is correct, and how to actually build it.

Common Mistakes to Watch For

  • Treating every environment identically — a mistake in a test environment costs little; the same mistake in production can be genuinely serious.
  • Confusing environment secrets (already covered in Chapter 7) with environment variables — related, but genuinely different mechanisms.
  • Adding an approval step everywhere "to be safe," even for deployments where the actual risk doesn't justify the friction.
