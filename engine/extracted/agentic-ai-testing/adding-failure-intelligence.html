🧠 Think About It

Why does determining the failing surface need to happen BEFORE evidence gathering, rather than gathering both browser AND API evidence for every failure regardless? This connects directly to Chapter 8's own cost-ordering principle — gathering full evidence for a surface that didn't actually fail would be genuinely wasteful, paying real cost for information that isn't diagnostically relevant. Determining the surface first is the cheap, quick check that determines which of the two more expensive evidence-gathering paths is actually worth pursuing.

⚠️ Common Mistake

Building an entirely new, surface-agnostic classification system from scratch to handle multi-surface failures, rather than recognizing that Chapter 8's existing function works unchanged once given the right surface-specific evidence. The genuine integration work is routing to the right evidence-gathering approach, not rewriting classification logic.

💡 Quick Tip

This page's failing_surface field in the historical run record is a genuinely small addition to Chapter 9's original schema — but skipping it would mean Chapter 9's flaky-detection function loses the ability to distinguish "this test is flaky on the browser step" from "this test is flaky on the API step," a real, useful distinction worth the minor schema addition.

Best Practices

  • Reuse Chapter 8 and 9's classification and detection functions exactly as written, routing to the correct surface-specific evidence rather than rewriting the underlying logic.
  • Determine which surface actually failed before gathering evidence, avoiding the waste of collecting both browsers' and API's evidence when only one is relevant.
  • Extend historical data schemas with small, purposeful additions (like a surface field) rather than large restructuring, when integration genuinely calls for it.

def classify_capstone_failure_v2(run_report, client):
    failing_step = find_failing_step(run_report["full_history"])
    surface = determine_surface(failing_step)

    # NEW: check whether the failing step's INPUT PARAMETERS
    # were derived from an EARLIER step's output — if so, the
    # GENUINE root cause might be at that EARLIER step, not
    # the surface where the failure ACTUALLY manifested
    data_source_step = trace_input_data_origin(
        failing_step, run_report["full_history"])

    if data_source_step and data_source_step["step"] != failing_step["step"]:
        # gather evidence for BOTH the MANIFESTING surface
        # AND the ORIGINATING surface
        evidence = (gather_surface_evidence(failing_step, surface) +
                    gather_surface_evidence(
                        data_source_step, determine_surface(data_source_step)))
    else:
        evidence = gather_surface_evidence(failing_step, surface)

    return classify_failure(evidence, client)
