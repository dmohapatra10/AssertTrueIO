What This Chapter Builds

One deliberately small, genuinely working agent that logs into ShopEasy and verifies the login actually succeeded — small enough to hold in your head completely, real enough to actually run. Later chapters build on this same foundation for genuinely harder tasks; this chapter's entire job is making sure that foundation is solid and genuinely understood, not just copy-pasted.

Common Mistakes to Watch For

  • Starting with a task that's too ambitious for a first build — a full checkout flow has too many moving parts to debug a first agent against; login is deliberately simpler.
  • Skipping instructions and hoping the LLM "figures it out" — Chapter 2 already showed that reasoning quality depends heavily on what the agent is actually given; instructions matter from the very first version.
  • Treating this chapter's simple agent as a toy to discard — every piece built here (setup, instructions, tools, loop, results) is the exact same shape later, genuinely more complex agents use.
