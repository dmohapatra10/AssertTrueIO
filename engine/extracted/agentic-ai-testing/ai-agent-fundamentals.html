Opening Up the Black Box

Chapter 1 described what an AI agent does — acts, observes, decides, repeats. This chapter opens up how, piece by piece. Every concept here gets its own focused page, deliberately not rushed together, because each one is a genuine building block you'll actually use once you start building real agents in Chapter 3:

  1. Anatomy of an AI Agent — the full picture, before the individual pieces
  2. LLMs and AI Agents — what the underlying model actually contributes, and doesn't
  3. Agent Planning — deciding a sequence of steps toward a goal
  4. Agent Reasoning — the moment-to-moment thinking that evaluates a specific situation
  5. Agent Memory — what an agent can actually recall, and for how long
  6. Tools and Tool Calling — how an agent actually acts in the real world
  7. Agent State — where an agent currently is in its task, right now
  8. Agent Loops — the cycle that ties every other piece together
  9. Guardrails and Permissions — keeping all of the above operating safely

Why Nine Separate Pages, Not Three

It would be tempting to compress "planning and reasoning" into one page, or "memory and state" into another — they sound similar. This course deliberately keeps them apart: planning and reasoning are genuinely different mental operations even in human problem-solving, and memory and state answer genuinely different questions ("what have I seen" versus "where am I right now"). Conflating them early makes debugging a real agent's behavior later genuinely harder, not easier.

Common Mistakes to Watch For

  • Treating "the AI agent" as one indivisible thing — when something goes wrong with a real agent later in this course, being able to point at which specific piece (planning? memory? a tool?) is misbehaving is a genuinely practical skill this chapter builds.
  • Assuming more memory or a bigger model automatically means a better agent — each piece has real trade-offs, covered honestly on its own page.
  • Skipping guardrails as "something to add later once the agent works" — the final page of this chapter makes the case for why that ordering is genuinely risky.

What You'll Be Able to Do

By the end of the nine pages that follow, you should be able to describe each piece of an AI agent's architecture individually, explain specifically what an LLM contributes versus what the surrounding agent system adds, distinguish planning from reasoning and memory from state with real examples, and understand why guardrails belong in an agent's design from the very start.
