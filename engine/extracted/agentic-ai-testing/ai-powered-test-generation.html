The Running Example for This Chapter

REQUIREMENT: ShopEasy supports discount codes at checkout.

- A code gives either a percentage discount (e.g. 15% off) or a
  fixed-amount discount (e.g. $10 off)
- Codes are case-insensitive
- Only one code may be applied per order
- Codes have an expiration date
- Some codes have a minimum order value to qualify
- An expired, invalid, or not-yet-qualifying code shows a clear
  error message and does not apply

This one requirement is genuinely rich enough to carry every concept in this chapter — it has natural positive cases, natural failure modes, real numeric boundaries, and genuinely unusual edge cases, all from one realistic feature.

Common Mistakes to Watch For

  • Treating AI-generated scenarios as automatically comprehensive — generation is a genuinely strong first draft, not a substitute for reviewing whether real coverage gaps remain.
  • Confusing boundary testing with edge cases — genuinely distinct categories, each with its own dedicated page in this chapter specifically to avoid this conflation.
  • Converting scenarios into automated tests without first validating them — this chapter's final page explains why validation belongs before conversion, not after.
