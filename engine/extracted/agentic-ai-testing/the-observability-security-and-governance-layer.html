Why does this page's audit record get created BEFORE the agent even runs, rather than after the run completes? Creating the record before execution means even a run that fails catastrophically, crashes, or never completes still has a genuine record that it was attempted and by whom — exactly the accountability guarantee an audit trail needs to provide, which recording only after successful completion would genuinely fail to deliver.

def audit_observability_and_security_coverage(all_capstone_tools):
    """Systematically checks whether every tool across all
    lower layers is genuinely wrapped with this layer's
    practices, rather than relying on spot-checked examples."""
    coverage_report = []
    for tool in all_capstone_tools:
        has_structured_logging = tool_calls_are_logged(tool)
        touches_external_content = tool_processes_untrusted_text(tool)
        has_injection_defense = (
            structural_separation_applied(tool)
            if touches_external_content else "N/A - no external content"
        )
        coverage_report.append({
            "tool_name": tool["name"],
            "structured_logging": has_structured_logging,
            "injection_defense": has_injection_defense,
        })
    gaps = [t for t in coverage_report
            if not t["structured_logging"] or t["injection_defense"] is False]
    return {"full_report": coverage_report, "genuine_gaps": gaps}
